# Рамка — фото на документы

Одностраничный сервис: из одного селфи делает фото на документы. Находит лицо, кадрирует по требованиям документа, заменяет фон, ретуширует кожу и собирает лист 10×15 для печати.

Вся обработка идёт в браузере посетителя, фото на сервер не отправляется. Серверная часть не нужна: достаточно раздать эти файлы по HTTPS.

## Состояние

Прототип. Оплата не подключена: кнопка «Получить без водяного знака» открывает файлы бесплатно, а отметка об оплате хранится в браузере. Кнопку «Сбросить оплату» перед запуском нужно убрать.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | Вся страница: разметка, стили и код |
| `vendor/fd/` | MediaPipe Face Detection: первичный поиск лица |
| `vendor/fm/` | MediaPipe Face Mesh: точки лица для кадра, ретуши и макияжа |
| `vendor/rvm/` | Robust Video Matting (MobileNetV3): удаление фона |
| `vendor/ort/` | ONNX Runtime Web: запускает модель удаления фона |
| `vendor/ss/` | MediaPipe Selfie Segmentation: запасное удаление фона |

Файлы моделей (`.tflite`, `.binarypb`, `.data`, `.onnx`) сохранены с расширением `.wasm`: так их отдаёт любой хостинг. Код страницы сам подставляет нужные имена.

Архив JSZip для кнопки «Скачать всё архивом» подключается с cdnjs, шрифты с Google Fonts. Для российской аудитории оба лучше положить рядом с сайтом.

## Как выложить

Скопируйте содержимое этой папки (`index.html` и `vendor`) на сайт, в корень или в любую подпапку. Нужны HTTPS и правильный тип `application/wasm` для файлов `.wasm` (у большинства хостингов он задан по умолчанию). Стоит включить сжатие и долгое кеширование для `vendor/`: модели весят около 35 МБ.

Открывать `index.html` двойным кликом с диска нельзя: браузер не даст странице загрузить модели. Для локальной проверки запустите в этой папке `python3 -m http.server` и откройте `http://localhost:8000`.

## Перед запуском

- подключить оплату и хранить отметку об оплате на сервере;
- добавить оферту, политику обработки персональных данных, согласие и cookie-баннер;
- сверить нормы размеров головы с требованиями ведомств;
- проверить лицензии моделей и библиотек из `vendor/` для коммерческого использования.
